# Security policy

This policy applies to every public DredsGG repository that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Please do not post the details in a public issue.

1. Open an issue in the affected repository titled **"Security report"**, with no technical details.
2. We will reply in that issue with a private way to send the details.

When you send them, include the repository and version, what you found, how to reproduce it step by step, and the impact you see. Do not include other people's data.

## Scope

In scope: the code in these repositories and the release files built from it.

Out of scope: the third-party sites and services the projects interact with (they have their own channels), denial of service, and social engineering.

There is no bug bounty.
