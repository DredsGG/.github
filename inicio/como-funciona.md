**Cada projeto tem o seu canal.** Quando sai versão nova no GitHub, o aviso chega sozinho no canal dele e em {{todas-as-releases}}, com o que mudou e o link para baixar.

**Quer ser avisado?** Clique com o botão direito no canal do projeto → Configurações de notificação → Todas as mensagens. Pode silenciar o resto.

**Como instalar ou atualizar:** o link do aviso leva à página de releases. Lá tem o zip ou o instalador e o passo a passo. Os projetos também avisam sozinhos quando tem versão nova.

**Aviso em vermelho = URGENTE:** correção importante, atualize assim que puder.

Ninguém posta aqui além dos avisos. Dúvidas e bugs vão pelo GitHub de cada projeto.
